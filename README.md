# Propuesta web DIRLAB

Prototipo estático para revisión. No es el sitio institucional publicado ni una instalación de Joomla.

## Publicar en GitHub Pages

1. Crea un repositorio llamado `propuesta-dirlab`. En GitHub Free, usa un repositorio público solo si la propuesta puede compartirse públicamente.
2. Sube el contenido de esta carpeta a la raíz del repositorio: `index.html`, `mockups/`, `.nojekyll` y este README. No subas el ZIP como sustituto de los archivos.
3. En Settings → Pages, selecciona Deploy from a branch, rama main y carpeta / (root). Guarda.
4. Espera a que termine el despliegue y abre la URL que indica GitHub Pages.
5. Comparte la URL raíz para la guía o añade `mockups/` para abrir directamente el home.

GitHub Pages debe tratarse como una publicación pública. La etiqueta noindex solicita no indexar, pero no protege el acceso.

## Actualizar

Los originales están en `propuesta/mockups/`. Esta carpeta es una copia para publicación. Tras modificar los originales, copia los HTML y assets actualizados a `mockups/` y súbelos al repositorio; conserva la guía index.html de la raíz.

No se incluyen los documentos del taller, el inventario de investigación ni los archivos de implementación Joomla.
